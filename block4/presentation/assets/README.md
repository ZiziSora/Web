# Media cho bài trình bày

Đặt bốn ảnh PNG vào thư mục này với đúng tên trong `../README.md` và các khung slide 12–13. Tải lại bài HTML sau khi thêm file. Ảnh được tự nhận diện; khung hướng dẫn biến mất khi file tải thành công.

Các khung hiện tại chỉ đánh dấu media cần bổ sung, chưa phải bằng chứng đã thu.
