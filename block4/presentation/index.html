useEffect(() => {
  const controller = new AbortController();

  requestStudents({ signal: controller.signal })
    .then(data => {
      if (controller.signal.aborted) return;
      setStudents(data);
      setPage(1);

    }).catch(error => {
      if (controller.signal.aborted) return;

src/api.js · đầy đủ hàm
export async function requestStudents(options = {}) {
  const response = await fetch('/api/students', options);
  const body = await response.json();
  if (!response.ok) throw new Error(
    body.message || 'Không thể xử lý yêu cầu.');
  return body;
}
loading · Đang tảiready · Hiện bảngerror · Thử lại

AbortController hủy request khi effect cleanup. Tăng loadAttempt chạy lại effect để thử tải lại.

Form xử lý dữ liệu người dùng nhập

Tên và email được giữ trong state của form; submit hợp lệ sẽ gọi callback do App truyền xuống.

AddStudentForm.jsx · handleSubmitlược trích
async function handleSubmit(event) {
  event.preventDefault();
  if (disabled || submitting.current) return;
  const validation = validateStudentInput({ name, email });
  if (!validation.student) {
    setNotice({ error: true, message: validation.message });
    return;
  }
  submitting.current = true;
  setSaving(true);
  // … xóa notice cũ …
  try {
    await onAddStudent(validation.student);
    setName(''); setEmail('');
    // … notice thành công …
  } catch (error) {
    // … notice lỗi; giữ input để thử lại …
  } finally {
    submitting.current = false;
    setSaving(false);
  }
}
AddStudentForm.jsx · controlled inputlược trích

app.post('/api/students', async (req, res) => {

10 / Cập nhật state

Sau POST, React cập nhật danh sách

Khi API trả thành công, App thêm Student vào state; form hoàn tất submit và xóa input.

Sequence diagram · luồng thành công

Mũi tên liền: gọi xử lý / gửi request. Mũi tên ngang nét đứt: response / hoàn tất. Trục dọc: lifeline, thời gian đi từ trên xuống.

src/App.jsx · addStudentđịnh dạng lại
async function addStudent(input) {
  const student = await requestStudents({
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(input)
  });
  setStudents(previous => [...previous, student]);
  setPage(pageCount(students.length + 1));
}
  • previous => [...previous, student] tạo mảng mới từ state mới nhất.
  • setPage chuyển tới trang cuối để thấy sinh viên vừa thêm.
  • React render lại StudentList với props mới; document hiện tại vẫn được giữ.
State được cập nhật sau khi server xác nhận đã lưu. Sau đó handleSubmit mới reset form.

Quan sát Network khi submit

Giữ log từ lúc tải trang, rồi thêm một sinh viên để so sánh các request trước và sau submit.

Trong khoảng submit, cần quan sát
  • POST /api/students có type fetch.
  • Payload chứa name và email.
  • Response 201 trả Student có id.
  • Không có request loại document mới.
WebSocket ở development

vite-hmr phục vụ cập nhật code

Khi chạy npm run dev, Vite chèn /@vite/client và mở WebSocket để báo thay đổi code. Dữ liệu sinh viên vẫn đi qua HTTP API.

Production không chạy Vite HMR. Giữ filter All khi chụp để không che request document.

Submit không reload là một dấu hiệu hỗ trợ. Kết hợp với HTML response và client render ở slide trước để xác nhận CSR.
