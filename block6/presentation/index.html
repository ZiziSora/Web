07 / Không tin phản hồi mù quáng

HTTP 200 chưa đủ — client còn kiểm tra envelope và cấu trúc dữ liệu

Một hàm api<T> gom lỗi kết nối, HTTP, JSON, lỗi nghiệp vụ và dữ liệu sai hình dạng.

api/client.ts + validation.tsLược trích
const res = await fetch(base + path, {
  ...options,
  headers: requestHeaders(options)
});

if (!res.ok) throw new ApiError(...);
const body = await res.json();
return responseData(path, options.method, body);

Validation dùng cả path và method để phân biệt list, detail, mutation và DELETE.

Kiểm tra cả thành công lẫn lỗi
  • List phải là mảng; detail/mutation phải là entity.
  • Giá, ID, boolean và các mảng quan hệ đúng kiểu.
  • error.message, fields, details.dishes cũng được kiểm tra.
Header theo body

requestHeaders

Chỉ thêm JSON Content-Type cho body chuỗi; GET/DELETE không body không tự gắn header này.

Kết quả

Component không cần biết lỗi đến từ mạng, HTTP hay nghiệp vụ; nó nhận thông điệp và dữ liệu có cấu trúc thống nhất.

08 / Hook tải dữ liệu dùng chung

useLoad chỉ trả trạng thái của request hiện tại

Hook gắn state với key, hủy request cũ và chuẩn hóa lỗi lạ trước khi đưa dữ liệu cho page.

Abort chặn cập nhật muộn; so sánh key thêm một lớp bảo vệ để page không nhận data/error của route trước.

hooks/useLoad.tsLược trích
set({ key, loading: true });
load(controller.signal).catch(error =>
  set({ key,
    error: error instanceof ApiError
      ? error : new ApiError('Vui lòng thử lại sau.'),
    loading: false })
);
const current = state.key === key;

data và error chỉ được trả khi key lưu trong state còn khớp key của lần render hiện tại.

12 / CORS, input và bí mật

Tách hai origin làm ranh giới hệ thống trở nên rõ ràng

API giới hạn origin; client chỉ gửi header cần thiết để GET không preflight nhưng các thao tác ghi vẫn đúng CORS.

CORS chính xác

Một SPA_ORIGIN

Chỉ phản hồi Access-Control-Allow-Origin khi origin khớp chính xác.

GET không preflight

Không tự gắn Content-Type

GET và DELETE không body để fetch tự quyết định header phù hợp.

Giới hạn body

express.json(32kb)

JSON sai trả 400; payload quá lớn trả 413.

Ghi dữ liệu

JSON + preflight

POST/PATCH có application/json; DELETE vẫn preflight vì method không đơn giản.

Header phản hồi

nosniff · no-store

Giảm đoán MIME và tránh cache phản hồi API nhạy cảm theo phiên làm việc.

Bí mật ở backend

DATABASE_URL

Không đặt bí mật trong VITE_*; frontend chỉ biết base URL công khai.

Escape hiển thị: JSX render text theo cơ chế escape mặc định; source không dùng dangerouslySetInnerHTML.
