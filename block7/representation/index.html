Áp dụng cho món: COUNT dùng cùng WHERE; đếm tổng, lấy ID và tải quan hệ trong transaction Repeatable Read.

const pages = Math.max(1,
  Math.ceil(total / query.pageSize));
const page = Math.min(query.page, pages);
const ids = await tx.$queryRaw(Prisma.sql`
  SELECT id FROM ${this.table(resource)}
  WHERE ${conditions.where}
  ORDER BY ${conditions.order}
  LIMIT ${query.pageSize}
  OFFSET ${(page - 1) * query.pageSize}
`);
const where = {
  id: { in: ids.map(row => row.id) }
};

Cuộn kích hoạt tải; query quyết định dữ liệu hợp lệ

Infinite Scroll dùng chung dữ liệu đã tải với Load More; IntersectionObserver chỉ tăng số mục hiển thị tại client.

RelationField.tsx · khung nguyên liệuLược trích · xuống dòng lại
if (!infinite || !s.hasMore || s.loading ||
    s.error || !sentinel.current ||
    search.trim() !== q) return;
const observer = new IntersectionObserver(
  entries => {
    if (entries.some(entry => entry.isIntersecting))
      load.current();
  },
  { root: root.current, threshold: 0.1 }
);
observer.observe(sentinel.current);
return () => observer.disconnect();

root là khung nguyên liệu, không phải toàn trang. Có nút “Tải thêm” để dùng bàn phím; lỗi dừng tự tải và cho thử lại.

Network: món tải từng trang, tập nhỏ tải toàn bộ

Mở web localhost:5176 → F12 → Network. Theo dõi Fetch/XHR để đọc JSON, rồi đối chiếu cột Type hoặc bộ lọc Doc.

  1. Clear log, mở thực đơn, chuyển trang 2.
    Chọn request dishes có query; xem Payload → Query String Parameters.
  2. Chỉ ra page=2 và pageSize=6.
    Response có tối đa 6 món, total và số trang. Không có mảng 1.000 món để client tự cắt.
  3. Form món → Tải thêm / cuộn trong khung.
    Request options/all trả đủ khoảng 20 mục. Sau khi tải xong, Tải thêm/cuộn tiếp không tạo request mới.
  4. Đổi filter hoặc sort.
    Món gửi request mang điều kiện và về trang 1. Đầu bếp/nguyên liệu xử lý tại client, không fetch mới. Cả hai không tải lại document.
