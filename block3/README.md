# Student Management SSR

Ứng dụng danh sách và thêm mới sinh viên bằng ExpressJS, EJS và file JSON.

## Chạy dự án

Yêu cầu Node.js 18 trở lên.

```bash
npm install
npm start
```

Mở `http://localhost:3000/students`.

Có thể đổi cổng bằng biến môi trường `PORT`.

## Kiểm thử

```bash
npm test
```

Thông tin sinh viên được lưu tại `data/students.json`. Ứng dụng không sử dụng database hoặc ORM.
