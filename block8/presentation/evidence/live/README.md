# Bằng chứng môi trường thật chưa thu thập

Chưa có Network, Application/Cookies, email SMTP hoặc ảnh PostgreSQL thật trong thư mục này.

Người dùng tự hoàn tất cấu hình/schema và chụp theo DEMO.md. Mỗi mã Rxx/Cxx/Sxx/Fxx/Xxx có một thư mục riêng. Không đưa `.env`, cookie jar thô, OTP, token hoặc credential vào tài liệu nộp.

Ảnh trong ../../assets chỉ là giao diện browser test cô lập, không thay thế bằng chứng môi trường thật.
